# Ethereum Network Overview Dashboard

## Project Overview

This project analyzes Ethereum on-chain activity using Dune Analytics.

The dashboard provides an overview of four important Ethereum network metrics:

- Daily Ethereum Transactions
- Daily Active Wallets
- Average Gas Used
- Daily Blocks Produced

The goal of this project is to understand Ethereum network activity over time through SQL queries and data visualization.

## Dashboard Metrics

### 1. Daily Ethereum Transactions

Tracks the number of transactions processed each day.

---

### 2. Daily Active Wallets

Shows how many unique wallets interact with Ethereum daily.

---

### 3. Average Gas Used

Measures the average gas consumed by Ethereum transactions.

---

### 4. Daily Blocks Produced

Displays the number of Ethereum blocks created each day.
